Advanced TaskManager is a fast, private task manager written in Rust. It shows what the built-in Task Manager hides — threads, memory maps, handles, drivers, live system events — and explains it in plain language, with a health score, bottleneck detection and automation.

Dashboard — your PC at a glance

  • What's slowing things down names the bottleneck and the processes behind it.

Processes — every detail, your columns

  • Search by name, PID, publisher, path, user or command line (Ctrl+F).
  • Tree view shows which program started which.
  • Heat colours highlight heavy CPU, memory, disk and GPU use.
  • Column sets for memory, disk, CPU, graphics, security or "who made it", and free ordering.
  • Right-click for every action; click for details down to threads, DLLs, memory regions, handles and the security token.

Uninstaller — remove programs completely

  • Every installed program with size, version, date and publisher; spot what's new this week.
  • Normal, silent or forced uninstall, then a leftover scan of the registry, folders, app data, shortcuts and services.
  • Registry keys are backed up before removal; files go to the Recycle Bin; anything shared with other programs is left unticked.
  • Plus Windows apps, browser extensions, junk and privacy cleaners, secure delete, restore points and Windows tools.

  • Whole NTFS drives scanned in seconds in the Admin view by reading the drive's file table directly; any folder can be walked in the Standard view.
  • Folder tree with each item's share of its parent, size, space on disk and counts.
  • Largest files anywhere, with wildcards, include/exclude patterns and limits.
  • Space per file type, and duplicate files you could remove.
  • A zoomable colour treemap: hover for details, double-click to dive in.
  • Right-click to open, show in Explorer, copy the path or move to the Recycle Bin. Export everything to CSV.

  • Disk response time and queue length reveal slow drives.

  • Windows from one minute to one hour of history.

  • Save the whole report as a web page to keep or share.
  • Companion pages: bottlenecks, behaviour, leak candidates, startup analysis, correlations and change impact.

How it works

Low overhead comes from asking Windows the right questions, the right number of times.

One native call

Every second, a single kernel query returns every process and thread with dozens of counters — no need to open each process.

Counters

Per-CPU times, memory lists, disk, GPU and thermal counters, network tables and connections are read alongside.

Merge

Rates, percentages and history are computed in one short step, then the window redraws.

Understand

Spikes, starts and exits go to the timeline; rules, profiles and schedules run; insights read the history.

On demand

Slow details — services, devices, memory maps, handles, event logs — are fetched in the background only when you open them.

Built with

  • Rust — native speed and memory safety
  • egui / eframe — fast, GPU-drawn interface
  • windows-sys — direct Windows API access
  • Windows' own tools for management data (CIM/WMI, powercfg)

Windows interfaces

  • Native system information and object queries
  • Performance Data Helper (PDH) counters
  • IP Helper tables for adapters and connections
  • Event Tracing for Windows with TDH decoding
  • Toolhelp, virtual-memory and token APIs

Private and safe by design

A tool that sees everything on your PC should tell no one about it.

🔒

Nothing leaves your PC

No telemetry, analytics, crash reports, accounts or auto-update. The app makes no network connections of its own.

🛡

Least privilege

Runs as a normal user until you choose the Admin view; administrator rights are requested through the standard Windows prompt.

🧹

Leaves no trace running

No installer, background service or driver. Close the window and everything stops. Your data stays in one folder you can delete.

✋

You stay in control

Changes happen only when you press a button or a rule you wrote fires. Ending processes and stopping services ask first.

🧪

Careful native code

Every buffer from Windows is size-checked, every handle closed, and risky lookups (like pipe names) are skipped.

📄

Open source

MIT licensed. Read the security policy and privacy policy.

Get started

Requirements: Windows 10 (1809+) or 11, 64-bit. To build: Rust stable (MSVC) and Visual Studio Build Tools.

Build and run

cd "E:\MyAPPS-AI\Advanced TaskManager"
cargo build --release
.\target\release\advanced_taskmanager.exe

Questions

Does it replace the Windows Task Manager?

It can be used instead of it, but nothing is replaced or changed in Windows. You can keep using both.

Why do some processes show "access denied"?

Windows protects system processes and other users' processes. The Admin view, running as administrator, can read them.

Does it slow my PC down?

The monitor typically uses about 10–15 ms of one processor core per second — the exact figure is in the status bar. Slow it down further in Settings → Monitoring.

Why are fan speeds and voltages not shown?

Most PCs do not report them to Windows; reading them needs a vendor kernel driver, which this app deliberately does not install. Temperatures from thermal zones, battery details and NVIDIA GPU data (when NVIDIA's tools are present) are shown.

Can I see how much internet each app uses?

Windows doesn't count bytes per app by default. The app shows each process's connections, and the Live system events page in the Admin view shows network activity per process as it happens.

Is the uninstaller safe?

It runs each program's own uninstaller first, then shows every leftover before anything is removed. Registry keys are backed up and can be restored with one click, files go to the Recycle Bin, and anything another installed program also uses is left unticked.

How fast is the disk space analyzer?

In the Admin view a whole NTFS drive is read straight from its file table, usually in seconds. In the Standard view folders are walked with several threads — about 260,000 files took around a second in testing.

Where are my settings?

In %APPDATA%\AdvancedTaskManager, together with snapshots, recordings, reports, dumps, uninstall history and registry backups. Delete that folder to remove everything.

Is it free?

Yes. It is open source under the MIT licence.
